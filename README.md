# 본질 학습법 — 게임 엔진 (MVP)

정적 웹앱(HTML/CSS/JS, 빌드 없음, 서버 없음). 휴대폰 브라우저에서 링크/QR로 열고, 한 번 열면 오프라인에서도 동작(PWA)합니다.

## 로컬에서 미리 보기
JSON을 `fetch`로 읽기 때문에 **파일을 더블클릭(file://)하면 동작하지 않습니다.** 간단한 http 서버가 필요합니다.

```bash
cd /workspace/bonjil/app
python3 -m http.server 8000
```
브라우저에서 http://localhost:8000/ 을 엽니다. (같은 와이파이의 폰에서는 `http://<컴퓨터IP>:8000/` — 단, 서비스 워커/홈 화면 추가는 localhost 또는 https에서만 동작합니다.)

## 폴더 구조
```
index.html          화면 틀
css/style.css       디자인
js/app.js           게임 엔진 (로더·검증·채점·화면)
sw.js               서비스 워커 (오프라인 캐시)
manifest.json       PWA 정보
icons/              앱 아이콘 (192, 512)
images/             문제 그림 넣는 곳
data/questions.json 문제 파일 (엔진이 읽는 유일한 파일)
screenshots/        테스트 스크린샷
```

## 문제 파일 갱신 (중요)
원본은 `/workspace/bonjil/content/questions.json`(수업 자료 담당자 작성)입니다. 앱은 자기 폴더 안의 `data/questions.json`만 읽으므로, 원본을 고친 뒤에는 복사하세요.
```bash
cp /workspace/bonjil/content/questions.json /workspace/bonjil/app/data/questions.json
```
그 다음 `version` 값을 1 올리고, 배포했다면 `sw.js`의 캐시 버전도 올리세요(아래 참고).

## JSON 형식
최상위:
```json
{ "title": "본질 학습법", "version": 1,
  "stages": [ { "id": 1, "title": "1단계 · 수열", "description": "다음 수를 맞혀 보자" } ],
  "questions": [ ... ] }
```
- `version` (숫자): 파일을 고칠 때마다 올립니다.
- `stages` (선택): 단계 제목/설명을 바꾸고 싶을 때만. 없으면 기본 제목(1 수열, 2 그래프 모양, 3 같은 구조 짝짓기, 4 구조가 다른 하나, 5 왜 그럴까)을 씁니다. **단계 목록은 문제의 `stage` 값으로 자동으로 만들어집니다.** stage 6 문제를 넣으면 6단계가 자동으로 생깁니다.

공통 필드 (모든 문제):
| 필드 | 필수 | 설명 |
|---|---|---|
| id | ○ | 고유 문자열 (예: "s3-007"). 진행 기록이 id로 저장되므로 한 번 쓰면 바꾸지 마세요 |
| stage | ○ | 단계 번호 |
| type | ○ | choice / number / group / oddOneOut / why |
| prompt | ○ | 문제 문장 |
| explanation | ○ | 답한 뒤 보여 줄 해설 (줄바꿈 `\n` 가능) |
| image | | 그림 경로, 예: "images/s2-007.png" |
| imageAlt | | 그림 설명(화면 낭독기용) |
| chart | | 그래프 데이터 (아래 참고) |
| summary | | 결과 화면 ⭕/❌ 목록에 보일 한 줄 요약(선택). 없으면 묶기=각 정답 묶음의 첫 카드, 다른 하나=정답 카드, 그 외=문제 첫 줄. 한 줄을 넘으면 …으로 줄임 |
| level | | 난이도 1~4. 1=★, 2=★★, 3=★★★, 4=**도전** 배지. 없으면 표시 안 함. 범위 밖 값은 경고 후 무시 |

단계당 문제 수는 정해져 있지 않습니다(8~10개 이상 자유). 진행 막대·점수·결과 요약이 문제 수에 맞춰 바뀝니다.

보기와 카드는 화면에서 **순서가 섞여** 나옵니다. 정답은 id로 채점하므로 순서는 신경 쓰지 않아도 됩니다.

### 1. choice — 객관식
```json
{ "id": "s1-001", "stage": 1, "type": "choice",
  "prompt": "2, 5, 8, 11, ?  다음에 올 수는?",
  "options": [ {"id":"a","text":"13"}, {"id":"b","text":"14"}, {"id":"c","text":"15"}, {"id":"d","text":"22"} ],
  "answer": "b",
  "explanation": "매번 3씩 더하는 등차수열이에요." }
```
`answer` = 정답 보기의 `id`.

### chart — 그래프 (주로 2단계, 어느 유형에나 붙일 수 있음)
```json
"chart": { "xLabel": "추의 질량(g)", "yLabel": "늘어난 길이(cm)",
           "points": [[0,0],[50,2],[100,4],[150,6],[200,8]],
           "note": "예시 값", "kind": "line" }
```
| 필드 | 설명 |
|---|---|
| points | [x, y] 숫자 쌍 2개 이상 (필수) |
| xLabel / yLabel | 축 이름. y축 이름은 그래프 위에 가로로 표시 |
| note | 그래프 아래 작은 글씨 (출처, "예시 값" 등) |
| kind | "line"(기본, 점+선) 또는 "scatter"(점만) |
| smooth | true면 점을 지나는 부드러운 곡선(단조 3차 보간, 점 사이에서 값이 튀지 않음). 주기·포화 데이터에 권장 |
| xTicks | x축 눈금 직접 지정: `[{"x":1,"label":"1년차 1월"},{"x":7,"label":"1년차 7월"}]`. 없으면 자동 |
| yTicks | y축 눈금 직접 지정: `[{"y":0,"label":"0"},{"y":25,"label":"25°C"}]`. 없으면 1·2·5 단위로 자동 |

예 (주기 데이터):
```json
"chart": { "xLabel": "월", "yLabel": "월평균 기온(°C)", "smooth": true,
  "points": [[1,-2.0],[4,12.6],[7,25.3],[10,15.0],[13,-2.0],[16,12.6],[19,25.3],[22,15.0]],
  "xTicks": [{"x":1,"label":"1년차 1월"},{"x":13,"label":"2년차 1월"}], "note": "서울 평년값(기상청)" }
```
눈금 글씨는 휴대폰에서 약 13px 이상(y축 제목 13px, note 12px)으로 보입니다. 라벨이 겹칠 만큼 많으면 글자 폭을 계산해 **자동으로 일부를 건너뛰어** 표시합니다(자동 눈금과 xTicks 모두). 중요한 눈금이 빠지지 않게 하려면 xTicks를 4~6개로, 라벨은 짧게(6자 안팎) 써 주세요.

### 2. number — 숫자 입력 (현재 콘텐츠에서는 미사용)
```json
{ "id": "s1-101", "stage": 1, "type": "number",
  "prompt": "1, 1, 2, 3, 5, 8, ?", "answer": 13, "tolerance": 0, "unit": "",
  "explanation": "앞의 두 수를 더하는 피보나치 수열이에요." }
```
`answer` 숫자, `tolerance`(선택) 허용 오차, `unit`(선택) 단위. 폰에서는 숫자 키패드가 뜹니다.

### 3. group — 같은 구조끼리 묶기
```json
{ "id": "s3-001", "stage": 3, "type": "group",
  "prompt": "구조가 같은 것끼리 묶어 보세요",
  "cards": [ {"id":"a","text":"세포 분열 1→2→4→8"}, {"id":"b","text":"계단을 한 칸씩 오름"},
             {"id":"c","text":"소문이 한 사람당 2명에게 퍼짐"}, {"id":"d","text":"매주 1000원씩 저금"},
             {"id":"e","text":"복리 이자"}, {"id":"f","text":"시계 초침이 일정하게 감"} ],
  "answer": [["a","c","e"],["b","d","f"]],
  "explanation": "..." }
```
- `answer` = 묶음들의 배열. **모든 카드가 정확히 한 번씩** 들어가야 합니다. 묶음 2~4개.
- 묶음 개수(= answer 길이)는 학생에게 힌트로 보여 줍니다.
- 채점은 순서 무관: 묶음 순서, 묶음 안 카드 순서가 달라도 정답.
- 학생 조작: 카드 탭(✓ 선택 표시) → `묶기`. `되돌리기 | 묶기 | 확인`은 화면 아래 고정 바에 함께 있어 카드가 많아도 항상 보입니다. 모든 묶음을 학생이 직접 만듭니다(자동 완성 없음). 카드 위에 '남은 카드 N장 · 묶음 k/N' 표시. `되돌리기`(마지막 묶음 풀기), `모두 풀기`(글자 링크).
- 틀리면 학생이 만든 묶음마다 ⭕/❌ 표시, 정답 묶음을 한 줄에 하나씩 보여 줍니다.
- 카드는 6~8장 권장.

### 4. oddOneOut — 구조가 다른 하나
```json
{ "id": "s4-003", "stage": 4, "type": "oddOneOut",
  "prompt": "구조가 다른 하나는?",
  "cards": [ {"id":"a","text":"멀어질수록 어두워지는 빛"}, {"id":"b","text":"멀어질수록 약해지는 중력"},
             {"id":"c","text":"시간이 지나면 식는 커피"}, {"id":"d","text":"멀어질수록 작아지는 소리"} ],
  "answer": "c", "explanation": "..." }
```
`answer` = 카드 `id` 하나.

### 5. why — 근본 원리 고르기
```json
{ "id": "s5-004", "stage": 5, "type": "why", "mode": "choice",
  "prompt": "빛의 밝기가 거리의 제곱에 반비례하는 까닭은?",
  "options": [ {"id":"a","text":"같은 빛이 구 표면(4πr²)에 퍼지기 때문"}, {"id":"b","text":"공기가 빛을 흡수하기 때문"} ],
  "answer": "a", "explanation": "..." }
```
choice와 같은 형식. `mode`(선택, 기본 "choice")는 나중에 서술형("text")을 위해 비워 둔 자리입니다. 현재 "choice" 외의 값은 건너뜁니다.

## 문제/단계 추가하기
1. `questions` 배열에 문제 객체를 추가(새 `id`).
2. 새 단계는 새 `stage` 번호만 쓰면 자동 생성. 제목은 `stages`에 추가.
3. 그림은 `images/` 폴더에 넣고 `"image": "images/파일명.png"`. 가로 800px 이하, 용량 200KB 이하 권장.
4. 브라우저를 새로고침하고 개발자 도구 콘솔을 확인: 잘못된 문제는 **`[본질 학습법] … 건너뜀 — 이유`** 경고와 함께 빠지고 나머지는 정상 동작합니다. 파일 자체가 깨지면(JSON 문법 오류) 화면에 "문제를 불러오지 못했어요"가 뜹니다. JSON 문법은 `python3 -m json.tool data/questions.json`으로 확인할 수 있습니다.

## 화면 동작 요약
- 시작 화면: 단계별 '최고 x/n'(또는 '이어서 풀기 k/n', 'n문제') 하나만 표시. 5단계가 390×844 화면에 스크롤 없이 들어갑니다.
- 시작 화면 아래에 난이도 범례(★ 쉬움 · ★★ 보통 · ★★★ 어려움 · 도전).
- 문제 화면: 맨 위 단계 이름, 굵은 진행 막대, 난이도 표시. ✕를 누르면 확인 창(계속 풀기 / 나가기; Esc·바깥 누름 = 계속 풀기)이 뜨고, 나가면 그 단계를 다시 누르면 같은 문제부터 이어서 풉니다.
- 오답 해설: '내 답'과 '정답'을 함께 보여 줍니다.
- 결과 화면: 문제별 ⭕/❌ 한 줄 요약(`summary` 참고). `다시 하기 | 다음 단계`는 하단 고정 바에 있어 스크롤 없이 보입니다.
- 디자인: 라이트/다크 모드 자동(기기 설정을 따름), '동작 줄이기' 설정 시 애니메이션 끔.

## 진행 기록
브라우저 localStorage의 `bonjil.v1` 키에 단계별 최고 점수, 맞힌 문제 id, 풀던 위치가 저장됩니다(새로고침하면 이어서). 시작 화면 맨 아래 "진행 상황 초기화"로 지울 수 있습니다. 문제 파일이 바뀌어 풀던 문제가 없어지면 그 단계는 처음부터 시작합니다.

## 서비스 워커 캐시 버전 올리기
`sw.js` 첫 줄 `const CACHE_VERSION = 'bonjil-v4';`(현재 값)을 `'bonjil-v5'`처럼 바꿉니다.
- 문제 JSON은 "네트워크 우선"이라 온라인이면 버전을 안 올려도 새 내용이 보입니다.
- HTML/CSS/JS/이미지는 "캐시 우선 + 백그라운드 갱신"이라, 코드를 바꾸면 **캐시 버전을 꼭 올리세요.** 학생 폰에서는 앱을 한두 번 새로 열어야 반영됩니다.
